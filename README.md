# LaTeX (Beamer) Presentation Template

A reusable **LaTeX / Beamer** presentation template accompanied by a fully worked
example talk (Yamal Peninsula field geoscience). It shows how to structure slides,
title frames, figures and references for professional academic presentations, and
includes the compiled PDF for reference.

## Contents

- \`Lemenkova_etal_Present_Yamal2012.tex\` - the LaTeX source of the presentation.
- \`Lemenkova_etal_Present_Yamal2012.pdf\` - the compiled slides.

## Technologies

LaTeX / TeX (Beamer document class).

## Usage

Use the \`.tex\` file as a template: replace the title, author, content frames and
figures with your own, then compile with \`pdflatex\` (run twice to resolve
references). The included PDF shows the expected result.
